# Issue tracker: GitHub

Issues and PRDs live in GitHub Issues for `Liuxd-1230/simplis-automation`.
Use the `gh` CLI for creation, reading, comments, labels, and closing.

When a skill says "publish to the issue tracker", create a GitHub issue.
When it says "fetch the relevant ticket", use `gh issue view <number> --comments`.
Infer the repository from `git remote -v`.
