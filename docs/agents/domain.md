# Domain Docs

This repository uses a single domain context.

Before architecture, diagnosis, or TDD work:

- Read root `CONTEXT.md` when it exists.
- Read relevant ADRs under `docs/adr/`.
- Use the glossary's established terminology.
- Surface conflicts with existing ADRs explicitly.
- If these files do not exist, proceed silently.

`CONTEXT.md` and ADRs are created lazily as domain terms and architectural
decisions become stable.
