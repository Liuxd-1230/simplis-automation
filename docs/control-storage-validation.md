## 控制电路与人工编辑

电路包含两个比较器、SR 锁存器、输出缓冲驱动、RC 网络、负载和反馈。
输出低于约 1.8 V 时置位，高于约 2.2 V 时复位；阈值之间由锁存器保持状态。
驱动器给 RC 网络充放电，比较器通过反馈决定下一次切换，形成周期运行。

参数：R1=1 kΩ、C1=10 nF、驱动输出电阻 10 Ω、负载初始 100 kΩ；比较器迟滞 2 mV，
比较器/锁存器/驱动延时分别为 2/2/5 ns；仿真 100 µs，稳态统计窗口 20–100 µs。
原生版本从首选符号构建，复用 v2 的实际引脚变换、完整标注占用范围和局部布线函数。

|实际运行|稳态输出最小值 / 最大值|驱动频率|
|---|---|---:|
|v2 YAML 自动排布|1.797381145 / 2.203472840 V|292.787791 kHz|
|原生两子模块|1.797381145 / 2.203472840 V|292.787791 kHz|
|原生交叉导线变体|1.797381145 / 2.203472840 V|292.787791 kHz|
|原生界面修改负载为 20 kΩ 后重新运行|1.797316440 / 2.203393597 V|296.223479 kHz|

核对实际导出的父子端口顺序、比较器/锁存器/驱动节点，以及 DRIVE 与 VOUT 的独立节点。
交叉变体在两条不同网络之间设置没有端点的几何交叉，网表和结果均确认没有误连接。
原生编辑使用官方 `Select /prop ref RLOAD`、`Prop VALUE 20k` 和 `SaveAs`，随后检查
新网表与波形。独立 v2 测试的 YAML 保持原样。

实际预览发现局部端口和器件标注重叠，现已将子模块端口放到独立边缘位置，并复用引脚朝外
标注方向；数字器件参考名称采用符号原有的顶部标注。自动行间距按前一个对象的完整标注
占用范围累加，避免不同尺寸的器件产生重叠后被横向移动。

同时修复 SR 检查对纯数字域 0/1 导出的幅度误判。输入必须切换的要求保留。
原生兼容检查改为识别实际错误，正常命令回显不再导致失败。

## 大波形测量

实际求解器生成 RC 波形：**1,000,001 点、3 个信号、72,000,319 字节**。
在两个独立 Python 进程中，用同一文件、同一 4–5 ms 窗口测量 V(2) 的时间均值。

|方式|Python 分配峰值|测量耗时|时间均值|
|---|---:|---:|---:|
|完整读取后积分|200,466,443 字节|7.406 s|0.9884223080367525 V|
|逐行读取并积分|62,265 字节|6.941 s|0.9884223080367500 V|

峰值由 `tracemalloc` 记录，表示 Python 分配量，未代表整个进程或求解器的内存。
事件左右极限、窗口边界插值、非均匀采样和完整文件检查均保留；原有完整读取 API 也保留。
补充检查了窗口结束后的截断数据仍会被拒绝。内存测量和理论 RC 均值核对使用真实求解器输出。
